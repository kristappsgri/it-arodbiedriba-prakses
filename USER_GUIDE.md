Lietotāja rokasgrāmata

Kā atvērt projektu:

1. Atver pārlūku (Chrome, Edge vai Firefox)
2. Ieraksti adresi: https://tavs-lietotajvards.github.io/it-arodbiedriba-prakse
   (tavs-lietotajvards aizstāj ar savu GitHub lietotājvārdu)
3. Nospied Enter - projekts atvērsies

Vai arī ja vēl nav GitHub Pages:
- Atver mapi datorā, kur atrodas index.html
- Divreiz uzklikšķini uz index.html

Ko lietotājs redz ekrānā:

Ir redzams virsraksts "IT Arodbiedrības biedri". Zem tā redzamas kartītes ar katra biedra vārdu un statusu. Pašlaik var tikai skatīties sarakstu - neko nevar pievienot, labot vai dzēst.

Ko darīt, ja kaut kas nestrādā:

- Pārbaudi, vai esi pieslēgts internetam
- Atsvaidzini lapu (nospied F5 vai Ctrl+R)
- Aizver un atver lapu no jauna
- Ja rāda tukšu sarakstu, pārbaudi, vai Supabase datu bāzē ir pievienoti biedri
